# Savvy Energy requirements
- Responsive solar equipment storefront with premium green visual identity.
- User-controlled light/dark theme with persisted preference and system preference default.
- Account registration/login/logout and role-aware admin navigation.
- Searchable and filterable product catalogue; 24 items initially, +50 on each Show More click.
- Product details including brand, model, description, price, stock and quantity selection.
- Cart, order submission, account order history and order status management.
- Checkout online payment through Paystack when configured and a quote-request alternative.
- Admin dashboard, product create/edit/archive, order management and quote request management.
- Modular React frontend and FastAPI/PostgreSQL backend with validation and protected administrative endpoints.
